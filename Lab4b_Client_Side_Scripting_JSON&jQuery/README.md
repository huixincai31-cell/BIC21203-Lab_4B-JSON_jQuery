## Introduction

This laboratory exercise focuses on client-side scripting using JSON, modern JavaScript and jQuery.

The objective is to develop webpages that demonstrate JSON data handling, retrieving data using the JavaScript fetch() API, DOM manipulation and jQuery integration.

## Files Included

1. **books.json** - A JSON dataset containing information about two books.
2. **books.html** - Retrieves and displays JSON data using the JavaScript fetch() API.
3. **jquery-dom.html** - Demonstrates DOM manipulation using jQuery.

## Requirements

- Visual Studio Code
- Modern web browser (Google Chrome)
- Live Server extension
- Internet connection for loading the jQuery CDN

## How to Run

1. Download or clone this repository.
2. Open the project folder using Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Right-click `books.html` and select **Open with Live Server**.
5. The webpage will retrieve and display the book information from `books.json`.
6. Open `jquery-dom.html` using Live Server to test the jQuery DOM manipulation operations.
