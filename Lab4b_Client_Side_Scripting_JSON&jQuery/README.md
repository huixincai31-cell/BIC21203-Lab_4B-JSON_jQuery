# Lab 4b: Client-Side Scripting (JSON and jQuery)

**Course:** BIC21203 Web Development  
**Academic Session:** 2026/2027

## Description
This laboratory activity demonstrates JSON data
handling, JavaScript fetch(), DOM manipulation,
and jQuery integration.

## Files Included

1. books.json - JSON dataset containing two books.
2. books.html - Retrieves and displays JSON data
   using the JavaScript fetch() API.
3. jquery-dom.html - Demonstrates DOM manipulation
   using jQuery.

## Requirements
- Visual Studio Code
- Modern web browser
- Live Server extension
- Internet connection for jQuery CDN

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Right-click books.html and select
   Open with Live Server.
5. Open jquery-dom.html using Live Server
   to test the jQuery operations.
